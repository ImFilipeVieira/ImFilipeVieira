### Template Zabbix para Hikvision
**Monitoramento avançado de CFTV corporativo via ISAPI**

Monitora em tempo real:
- Disponibilidade dos equipamentos
- Status das câmeras e eventos de gravação
- Funcionamento e integridade das gravações
- Saúde dos discos rígidos (SMART, setores corrompidos)
- Falhas de armazenamento e degradação

Valor operacional: visibilidade proativa, MTTR reduzido, conformidade de SLA para ambientes críticos

📍 Repositório: [github.com/ImFilipeVieira/zabbix-hikvision-template](https://github.com/ImFilipeVieira/zabbix-hikvision-template)
