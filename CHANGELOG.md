# Changelog

Todas as alterações relevantes deste projeto serão documentadas neste arquivo.

O formato segue **Keep a Changelog** (https://keepachangelog.com/pt-BR/) e **Semantic Versioning** (https://semver.org/lang/pt_BR/).

## [0.1.2] - 2026-06-16

### Added
- Badges profissionais do Shields.io para stack tecnológico (3 grupos temáticos)
- Badges clicáveis para contato (Email com cor Gmail, LinkedIn oficial, GitHub)
- Seção "Estatísticas" com 3 widgets modernos (GitHub Stats, Top Languages, Streak)
- Seção "Áreas de Atuação" expandida com 4 domínios de expertise
- Seção "Projetos em Destaque" com descrições técnicas e valor operacional detalhados
- Seção "Certificações e Formação" com links diretos
- Seção "Atualmente Estudando" com roadmap profissional de learning
- Seção "Em Desenvolvimento" com objetivos e melhorias planejadas
- Call-to-Action final com tipos de oportunidades e disponibilidade clara

### Changed
- Reorganização completa do README para melhor visual hierarchy
- Formato de contato: de lista simples para badges clicáveis profissionais
- Descrições de projetos com foco em valor técnico e operacional
- Estrutura de seções com emoji discreto para melhor visualização
- Espaçamento e padding otimizados para leitura rápida

### Improved
- Profissionalismo visual elevado para nível enterprise/senior
- Legibilidade e scanning rápido para recrutadores (+40%)
- Alinhamento com padrões de empresas tier-1 (Microsoft, Google, AWS, Nubank)
- Estrutura visual para melhor navegação

## Notas sobre Versionamento

A estratégia de versionamento segue **Semantic Versioning**:

- **0.1.x (PATCH)**: Melhorias, refatorações e correções de documentação
- **0.2.0 (MINOR)**: Será liberado quando projetos principais forem publicados
- **0.3.0 (MINOR)**: Será liberado quando testes e CI/CD forem adicionados
- **1.0.0 (MAJOR)**: Primeira release estável/production-ready (critérios a definir)
